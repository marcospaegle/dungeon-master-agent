# Glossary — Fluent Python (2nd ed.)

Alphabetical; chapter references in parentheses.

**`!r`** — f-string conversion applying repr (Ch 1)
**@contextmanager** — decorator making a single-`yield` generator into a context manager (Ch 18)
**@overload** — typing decorator declaring alternative signatures (Ch 15)
**@runtime_checkable** — lets a Protocol work with isinstance; checks method names only (Ch 13)
**add_done_callback** — run callable with future when done (in the worker) (Ch 20)
**Aggregate class** — class built only from bases/mixins, adds nothing (Ch 14)
**as_completed** — iterator yielding futures as they finish (Ch 20)
**BOM** — byte order mark U+FEFF; `utf-8-sig` handles it (Ch 4)
**Canonical equivalents** — different code point sequences meaning the same text (Ch 4)
**Case folding** — `str.casefold()`, aggressive lowercase for comparisons (Ch 4)
**ChainMap** — layered lookup over several mappings (Ch 3)
**classic coroutine** — generator used as data consumer via `.send()`; must be primed (Ch 17)
**Code point** — Unicode character identity U+0000..U+10FFFF (Ch 4)
**Collection ABC** — Iterable + Sized + Container (Ch 1)
**Combining character** — mark attaching to previous char (`unicodedata.combining`) (Ch 4)
**concurrency vs parallelism** — handling many tasks vs executing simultaneously (Ch 19)
**Container sequence** — holds references to any objects (list, tuple, deque) (Ch 2)
**context manager** — object with `__enter__`/`__exit__` controlling a `with` block (Ch 18)
**ContextDecorator** — lets a context manager double as function decorator (Ch 18)
**Cooperative method** — method that calls super().m() (Ch 14)
**Counter** — mapping of tallies / multiset (Ch 3)
**defaultdict** — dict that creates values via `default_factory` on `d[k]` (Ch 3)
**delegating generator / subgenerator** — generator using `yield from` / the one it delegates to (Ch 17)
**deque** — thread-safe double-ended queue, optional `maxlen` (Ch 2)
**Diamond problem** — name conflicts with shared ancestor in multiple inheritance (Ch 14)
**dictcomp / setcomp** — comprehensions for dict/set (Ch 3)
**Dictionary view** — dynamic read-only keys/values/items; keys/items behave like sets (Ch 3)
**distributed task queue** — Celery/RQ: producers enqueue, consumers on other machines work (Ch 19)
**Dual-mode API** — function behavior depends on str vs bytes arg (Ch 4)
**Duck typing** — runtime, structural: just use the object, EAFP (Ch 13)
**Dunder** — "double underscore" shorthand (Ch 1)
**Dynamic protocol** — informal interface; partial implementation OK (Ch 13)
**EAFP / LBYL** — ask forgiveness (try/except) vs look before you leap (if-checks) (Ch 18)
**Ellipsis** — `...`, single instance of `ellipsis` class (Ch 2)
**embarrassingly parallel** — independent subtasks, no coordination (Ch 20)
**Encoding / decoding** — str -> bytes / bytes -> str (Ch 4)
**Environment (ChainMap)** — chained scopes with `change()` for in-place update (Ch 18)
**event loop** — single-thread scheduler driving coroutines (Ch 19)
**execution unit** — process, thread, or coroutine (Ch 19)
**Executor** — `concurrent.futures` interface (`submit`, `map`, `shutdown`) over pools (Ch 20)
**ExitStack** — manages a dynamic number of context managers, LIFO exit (Ch 18)
**Fail fast** — raise errors as early as possible, e.g. list(arg) in __init__ (Ch 13)
**Flat sequence** — stores raw values in own memory (str, bytes, array) (Ch 2)
**Forward / reverse method** — __add__ / __radd__ (Ch 16)
**frozenset** — immutable, hashable set (Ch 3)
**Future** — deferred computation handle; created only by framework (Ch 20)
**generator expression** — lazy counterpart of list comprehension; builds a generator object (Ch 17)
**generator function** — function containing `yield`; calling returns a generator object (a generator factory) (Ch 17)
**Generator[Y, S, R]** — type for yield/send/return types; Y,R covariant, S contravariant (Ch 17)
**Generic type / formal / parameterized / actual type parameter** — Bloch terminology (Ch 15)
**get_type_hints / inspect.get_annotations** — resolve annotations at runtime (Ch 15)
**GIL** — Global Interpreter Lock; one Python thread runs at a time, 5 ms switch interval (Ch 19)
**Goose typing** — runtime isinstance/issubclass against ABCs (Ch 13)
**greenlet / gevent** — lightweight cooperative coroutines; gevent monkey-patches sockets (Ch 19)
**Guard** — `if` clause on a case evaluated after pattern match (Ch 2)
**Hashable** — fixed `__hash__` + `__eq__`; equal objects equal hashes (Ch 3)
**In-place operator method** — __iadd__ etc.; must mutate and return self (Ch 16)
**Infix / unary operator** — a+b vs -a, +a, ~a (Ch 16)
**Invariant / covariant / contravariant** — subtype relation of C[A] vs C[B] given A vs B (Ch 15)
**iter(callable, sentinel)** — two-arg form building an iterator that stops at the sentinel (Ch 17)
**iterable** — object from which `iter()` can get an iterator: `__iter__`, or `__getitem__` with 0-based ints (Ch 17)
**iterator** — object with `__next__` and `__iter__` returning self; exhausted ones can't be reset (Ch 17)
**Key-sharing dict** — PEP 412 shared key table across instances' `__dict__` (Ch 3)
**Late binding** — method lookup starts at receiver's class (Ch 14)
**lazy vs eager** — produce values on demand vs build everything up front (Ch 17)
**listcomp / genexp** — bracketed list builder / lazy parenthesized generator (Ch 2)
**MappingProxyType** — read-only dynamic mapping view (Ch 3)
**__matmul__** — @ operator (PEP 465) (Ch 16)
**max_workers default** — threads `min(32, cpu_count()+4)`; processes `cpu_count()` (Ch 20)
**memoryview** — shared-memory view; `.cast` reinterprets without copying (Ch 2)
**Metaobject protocol** — API for core language constructs; synonym for object model (Ch 1)
**`__missing__`** — hook called by `dict.__getitem__` on missing key (Ch 3)
**Mixin class** — class meant to be combined with others, never alone, no state (Ch 14)
**Mixin method** — concrete method in a collections.abc ABC (Ch 13, 14)
**Mojibake** — garbled text from wrong decoding (Ch 4)
**Monkey patching** — changing class/module at runtime (Ch 13)
**MRO / __mro__** — C3 linearization of a class and its bases (Ch 14)
**NFC/NFD/NFKC/NFKD** — Unicode normalization forms (Ch 4)
**NotImplemented** — singleton returned to decline an operand; not NotImplementedError (Ch 16)
**`ob_size`** — C field making `len()` fast on built-ins (Ch 1)
**OR-pattern** — `p1 | p2` in `case`; all alternatives must bind same names (Ch 18)
**PEP 563** — postponed evaluation of annotations as strings (Ch 15)
**poison pill** — sentinel telling a worker to exit (Ch 19)
**preemptive vs cooperative multitasking** — OS interrupts vs explicit `await`/`yield` (Ch 19)
**priming** — `next(coro)` or `.send(None)` to advance to first `yield` (Ch 17)
**Procedure** — class implementing a closure in lis.py (Ch 18)
**proper tail call (PTC)** — jump into callee without new stack frame; CPython lacks it (Ch 18)
**Python Data Model** — the API/metaobject protocol describing Python as a framework (Ch 1)
**race condition** — bug depending on order of concurrent actions (Ch 19)
**`__repr__` / `__str__`** — unambiguous debug string vs end-user string; prefer repr if only one (Ch 1)
**Reversed operator** — `__radd__` etc., tried on 2nd operand (Ch 1)
**Rich comparison** — ==, !=, <, >, <=, >= with shared methods (Ch 16)
**S-expression** — Lisp prefix-notation syntax; parsed into nested lists (Ch 18)
**Sequence pattern** — match/case pattern; not for str/bytes/bytearray (Ch 2)
**Slice object** — `slice(a, b, c)` passed to `__getitem__` (Ch 2)
**Special (dunder/magic) method** — method named `__x__` invoked by the interpreter for syntax/built-ins (Ch 1)
**Static duck typing** — structural typing checked statically via typing.Protocol (Ch 13)
**Static protocol** — typing.Protocol subclass; all methods required (Ch 13)
**StopIteration** — signals iterator exhaustion; its `.value` carries a generator's `return` value (Ch 17)
**__subclasshook__** — ABC classmethod enabling structural issubclass (Ch 13)
**super()** — dynamic proxy that binds the next method in the MRO to the receiver (Ch 14)
**Task** — asyncio wrapper that schedules a coroutine; `.cancel()` raises `CancelledError` (Ch 19)
**ThreadPoolExecutor / ProcessPoolExecutor** — pool of threads (I/O) / processes (CPU) (Ch 20)
**Timsort / stable sort** — adaptive sort preserving order of equal items (Ch 2)
**Traits** — explicit mixin construct in other languages (Ch 14)
**Truthiness** — `__bool__`, else `__len__`, else True (Ch 1)
**Tuple as record** — positional fields, meaning given by position (Ch 2)
**TYPE_CHECKING** — constant True only for static checkers (Ch 15)
**TypedDict** — checker-only fixed-key dict type; plain dict at runtime (Ch 15)
**Typing Map** — 2x2 of runtime/static x structural/nominal (Ch 13)
**typing.cast** — runtime no-op; tells checker to trust a type (Ch 15)
**UCA / pyuca** — Unicode Collation Algorithm, portable sorting (Ch 4)
**Unicode sandwich** — decode early, process str, encode late (Ch 4)
**Unpacking / destructuring** — extracting items by position; pattern-matching form of it (Ch 2)
**UserDict** — dict wrapper by composition (`self.data`), base for custom mappings (Ch 3)
**UserDict/UserList/UserString** — Python-coded, subclass-friendly wrappers of built-ins (Ch 14)
**Virtual subclass** — class registered with ABC.register; no inheritance, not in __mro__, unchecked (Ch 13)
**Walrus leakage** — `:=` in comprehension binds in the enclosing function (Ch 2)
**WSGI / ASGI** — sync / async server gateway interfaces (Ch 19)
**yield from** — delegates to a subgenerator, passing values through and capturing its return value (Ch 17)
